# Reconstruction comparisons

These are model renders, not photographs of a built product. `before` is the earlier narrow clipboard study; `after` uses the new four-view proportions and the same planar linkage trajectory. JSON files freeze the geometry rendered. Run Blender with `--background --factory-startup --python renders/render.py` from the repository root to regenerate. Source photographs are retained locally for comparison; the public source and dimension notes link to Craighill.
